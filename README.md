# Stackz

Real-time multiplayer Tetris where the crowd backs every match. This repo is a pnpm monorepo. Project context and rules live in [`skill.md`](skill.md).

```
apps/web/            React + Vite waitlist site (Cloudflare)
apps/api/            Hono API (Render)
packages/shared/     zod schemas, API types, brand tokens
supabase/migrations/ Postgres schema
```

## Branches

- `main`: all work. Commits and PRs go here.
- `live`: what Render, Cloudflare and Supabase deploy from. Only promoted from `main`, and only when the team says so.

## Local development

Requires Node 24 and pnpm (`corepack enable`).

```sh
pnpm install
pnpm dev        # API on http://localhost:8787 (in-memory store), site on http://localhost:5173
```

No env files need copying: the API reads `apps/api/.env.example` for local defaults, then `apps/api/.env` if you create one. `pnpm dev:api` and `pnpm dev:web` start one side each. Waitlist review: `pnpm admin` (see `build.md`).

The site's sounds live in `apps/web/public/sfx/`. They are generated by `tools/sfx/synth.py`; see `tools/sfx/README.md`.

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm format
```
